## 本地预览

```bash
python3 -m http.server 8898      # http://127.0.0.1:8898
```

不要用 `file://` 直接打开：页面虽为纯静态，但用本地服务器可保证相对路径与字体渲染一致。

## 部署

纯静态，任选其一：

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` / `root`，即可通过 `https://ichengplus6.github.io/aibrainpw/` 访问。
- **自有服务器 / 对象存储**：整个仓库内容（除 `.git`、`README.md`）上传至站点根目录。
- **CDN / 静态托管（Vercel、Netlify 等）**：框架预设选 Other，输出目录填 `.`。

## 技术说明

- 无框架、无构建、无外部字体与统计脚本，单文件即可离线打开。
- 响应式断点：1080 / 860 / 640px；移动端隐藏导航链接改用抽屉菜单。
- 可访问性：语义化 `header/main/section/footer`、跳过导航链接、`aria-selected` 标签组、`prefers-reduced-motion` 降级。
